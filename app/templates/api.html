Usage Examples

All API calls need Authorization: Bearer <token>.

Issue from an existing CA

curl -X POST http://localhost:8000/api/v1/certificates \
  -H "Authorization: Bearer $LABCA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "issuer_ca_id": "ca-id-here",
    "common_name": "service.lab",
    "dns_sans": ["service.lab"],
    "key_algorithm": "RSA",
    "key_size": 2048,
    "hash_algorithm": "SHA256",
    "validity_days": 365,
    "usage_preset": "server_tls",
    "return_private_key": true,
    "store_in_db": true
  }'

Self-signed certificate (no CA)

curl -X POST http://localhost:8000/api/v1/certificates \
  -H "Authorization: Bearer $LABCA_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "issuer_ca_id": null,
    "common_name": "dev.lab",
    "dns_sans": ["dev.lab", "localhost"],
    "key_algorithm": "ECDSA",
    "curve": "P-256",
    "hash_algorithm": "SHA256",
    "validity_days": 30,
    "return_private_key": true
  }'

Fetch certificate details

curl -X GET "http://localhost:8000/api/v1/certificates/{certificate_id}?include_private_key=false" \
  -H "Authorization: Bearer $LABCA_TOKEN"

Set include_private_key=true to retrieve the key when policy allows it. The response always includes certificate_pem plus metadata (owner, validity, status, tags, and whether key downloads are allowed).

Python quick start

import requests

token = "YOUR_TOKEN_HERE"
resp = requests.post(
    "http://localhost:8000/api/v1/certificates",
    headers={"Authorization": f"Bearer {token}"},
    json={
        "issuer_ca_id": "ca-id-here",
        "common_name": "api.lab",
        "dns_sans": ["api.lab"],
        "key_algorithm": "RSA",
        "key_size": 2048,
        "hash_algorithm": "SHA256",
        "validity_days": 90,
        "return_private_key": True,
    },
    timeout=10,
)
resp.raise_for_status()
bundle = resp.json()
print(bundle["certificate_pem"])
